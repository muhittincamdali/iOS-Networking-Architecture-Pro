iOS 16+, macOS 13+, tvOS 16+, watchOS 9+ ve visionOS 1+ uygulamaları için, `URLSession` üzerine kurulu ve hiçbir bağımlılığı olmayan bir ağ katmanı. API'nizin her çağrısını bir kez, türlü bir `Endpoint` olarak tanımlar ve `NetworkClient` ile gönderirsiniz; yeniden deneme, token yenileme, önbellekleme, günlük kaydı ve akış, her isteğin etrafına kendiniz yazacağınız kod yerine istemcinin ayarlarıdır.

## Öne çıkanlar

- **Türlü endpoint'ler** — `Endpoint<User>.get("users/42")` JSON'u `User`'a çözer;
  `Endpoint<Data>` gövdeyi olduğu gibi döndürür, `Endpoint<Void>` ise yok sayar. JSON, form ve
  multipart gövdeler desteklenir; yollardaki kullanıcı girdisi için `PathSegment` vardır.
- **Hatalar tek yerde ele alınır** — üstel geri çekilme (exponential backoff), jitter ve
  `Retry-After` destekli bir `RetryPolicy`, bir `CircuitBreaker`, çevrimdışıyken önbelleğe
  düşme, bağlantının koptuğu yerden devam eden indirmeler ve çevrimdışı bir cihazı 404'ten ya da
  JSON'a artık uymayan bir modelden ayıran tek bir `NetworkError` türü.
- **Doğru token yenileme** — `BearerTokenAuthenticator`, 401 alan tüm istekler için token'ı tek
  sefer yeniler, bu isteklerin her birini bir kez yeniden dener ve token'ı yalnızca sizin
  sunucularınıza gönderir.
- **Akış** — HTML standardının kurallarına göre ayrıştırılan server-sent events ve geri çekilmeyle
  yeniden bağlanan, ping'lerle bağlantıyı canlı tutan bir WebSocket.
- **Varsayılan olarak güvenli** — public key pinning, farklı kaynağa yönlendirmelerde kimlik
  bilgisi başlıklarının düşürülmesi, günlüklerden ve `curl` çıktısından gizli bilgilerin
  maskelenmesi; ayrıca yanıt boyutu, arabelleğe alınan mesajlar ve bekleme süreleri için sınırlar.
- **Test edilebilir** — `MockTransport` istekleri hazır yanıtlarla karşılar; paketin kendi 194
  Swift Testing testi macOS'ta çalışır, bunların 193'ü ayrıca bir iPhone simülatöründe de
  çalışır. Bunlara yerel bir HTTP, TLS ve WebSocket sunucusuna karşı yazılmış testler de dahildir.

## Hızlı başlangıç

**1. Paketi ekleyin**

Xcode'da **File › Add Package Dependencies…** menüsünü seçin ve depo adresini girin:

```text
https://github.com/muhittincamdali/iOS-Networking-Architecture-Pro.git
```

Adresi pencerenin sağ üstündeki arama alanına yapıştırın. **Dependency Rule** ayarını `2.0.0`
sürümünden başlayan **Up to Next Major Version** olarak bırakın ve **Add Package**'a tıklayın.
Sonraki pencerede **NetworkingArchitecture** yanındaki listeden uygulama hedefinizi seçin ve
yeniden **Add Package**'a tıklayın.

**2. Modülü içe aktarın**

```swift
import NetworkingArchitecture
```

**3. Kullanın**

Yanıtı bir `Decodable` türü olarak tanımlayın ve bir endpoint gönderin. Aşağıdaki kod, ücretsiz
bir test API'si olan JSONPlaceholder'dan bir gönderi yükler:

```swift
struct Post: Decodable, Sendable {
    let id: Int
    let title: String
}

func loadFirstPost() async throws -> Post {
    let client = NetworkClient(baseURL: URL(string: "https://jsonplaceholder.typicode.com")!)
    return try await client.send(Endpoint<Post>.get("posts/1"))
}

struct FirstPostView: View {
    @State private var title = "Loading…"

    var body: some View {
        Text(title)
            .padding()
            .task {
                do {
                    title = try await loadFirstPost().title
                } catch {
                    title = error.localizedDescription
                }
            }
    }
}
```

`FirstPostView()` görünümünü `ContentView` içinde gösterip uygulamayı çalıştırın: yanıt
çözüldüğünde 1 numaralı gönderinin başlığı görünür; URL ya da JSON için tek satır kod yazmanız
gerekmez.

### API'nizi bir kez tanımlayın

Her endpoint kendi metodunu, yolunu, gövdesini ve yanıt türünü bilir. Kullanıcıdan gelen bir değer
`PathSegment` üzerinden geçer; böylece `ada?admin=1` gibi bir ad tek bir yol parçası olarak kalır.

```swift
struct User: Codable, Sendable, Identifiable, Hashable {
    let id: Int
    let name: String
}

struct NewUser: Encodable, Sendable {
    let name: String
}

enum API {
    static func users(page: Int) -> Endpoint<[User]> {
        .get("users", query: [URLQueryItem(name: "page", value: String(page))])
    }

    static func user(named name: String) -> Endpoint<User> {
        .get("users/by-name/\(PathSegment(name))")
    }

    static func createUser(_ user: NewUser) -> Endpoint<User> {
        .post("users", body: .json(user))
    }

    static func deleteUser(id: Int) -> Endpoint<Void> {
        .delete("users/\(id)")
    }
}
```

### Bir istemci yapılandırın

API başına bir istemci, temel URL'yi ve tüm isteklere uygulanan her şeyi tutar: kimlik doğrulayıcı,
circuit breaker, günlükçü, önbellek ve yeniden deneme politikası.

```swift
func makeClient(savedToken: BearerToken?, refresh: @escaping BearerTokenAuthenticator.Refresh) -> NetworkClient {
    let authenticator = BearerTokenAuthenticator(
        token: savedToken,
        allowedHosts: ["api.example.com"],
        refresh: refresh
    )

    var configuration = NetworkClient.Configuration()
    configuration.decoder.keyDecodingStrategy = .convertFromSnakeCase
    configuration.interceptors = [authenticator, CircuitBreaker()]
    configuration.monitors = [NetworkLogger(detail: .headers)]
    configuration.cache = HybridResponseCache()
    configuration.retryPolicy.maximumAttempts = 4

    return NetworkClient(baseURL: URL(string: "https://api.example.com/v1")!, configuration: configuration)
}
```

### Hataları ele alın

Her hata bir `NetworkError`'dır; bu yüzden bir `catch` bloğu çevrimdışı bir cihazı bulunamayan bir
kaynaktan ayırt edebilir.

```swift
enum LoadState: Equatable {
    case loaded([User])
    case offline
    case notFound
    case failed(String)
}

func loadUsers(with client: NetworkClient) async -> LoadState {
    do {
        return .loaded(try await client.send(API.users(page: 1)))
    } catch let error as NetworkError where error.isConnectivityProblem {
        return .offline
    } catch NetworkError.unacceptableStatusCode(404, _) {
        return .notFound
    } catch {
        return .failed(error.localizedDescription)
    }
}
```

### Yanıtları önbelleğe alın

Yapılandırmada bir önbellek varsa endpoint kendi `CachePolicy` değerini seçer. Yanıt, nereden
geldiğini bildirir.

```swift
func cachedUsers(with client: NetworkClient) async throws -> HTTPResponse<[User]> {
    let endpoint = API.users(page: 1).with(\.cachePolicy, .cacheFirst(maxAge: .seconds(300)))
    let response = try await client.response(for: endpoint)
    print(response.source) // .network the first time, .cache for the next five minutes
    return response
}
```

### İlerleme göstererek yükleyin

`upload`, endpoint'in gövdesini (burada bir multipart form) gönderir ve ne kadarının gönderildiğini
bildirir. Alan ve dosya adları kaçışlanır; bu yüzden kendi başlıklarını ekleyemezler.

```swift
struct Photo: Decodable, Sendable {
    let id: Int
}

func uploadPhoto(_ jpeg: Data, with client: NetworkClient) async throws -> Photo {
    var form = MultipartFormData()
    form.append("Holiday", name: "title")
    form.append(jpeg, name: "photo", fileName: "beach.jpg", mimeType: "image/jpeg")

    let response = try await client.upload(Endpoint<Photo>.post("photos", body: .multipart(form))) { progress in
        print("Sent \(Int((progress.fractionCompleted ?? 0) * 100)) %")
    }
    return response.value
}
```

### Server-sent events akışını dinleyin

`events(_:)` her olayı geldiği anda verir ve bağlantı koptuğunda `Last-Event-ID` ile yeniden bağlanır.

```swift
struct PriceUpdate: Decodable, Sendable {
    let symbol: String
    let price: Double
}

func watchPrices(with client: NetworkClient) async throws -> [PriceUpdate] {
    var updates: [PriceUpdate] = []
    for try await event in client.events(.get("prices/stream")) where event.type == "price" {
        updates.append(try event.decode(PriceUpdate.self))
    }
    return updates
}
```

### GraphQL işlemleri çalıştırın

```swift
struct ViewerData: Decodable, Sendable {
    struct Viewer: Decodable, Sendable { let login: String }
    let viewer: Viewer
}

func viewerLogin(with client: NetworkClient) async throws -> String {
    let operation = GraphQLOperation<ViewerData>("query { viewer { login } }")
    return try await client.graphQL(operation).viewer.login
}
```

### API katmanınızı test edin

`MockTransport` senaryolanmış yanıtlar verir; aşağıdaki örnek bir kez 503 ile başarısız olur, sonra
başarılı olur; böylece istemcinin yeniden denemesi de testin parçası olur.

```swift
func makeTestClient() throws -> (NetworkClient, MockTransport) {
    let transport = MockTransport()
    transport.register(.get, "users", .status(503), try .json([User(id: 1, name: "Ada")]))
    let client = NetworkClient(baseURL: URL(string: "https://api.example.com/v1")!, transport: transport)
    return (client, transport)
}
```
